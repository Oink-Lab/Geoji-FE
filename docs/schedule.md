# 거지앱 V1 프론트엔드 개발 일정

- 기준: 기능명세서 V0.4 (`docs/spec.md`), Figma 「V0.4 개발용」 페이지 화면 40개
- 기간: 2026-11-09 ~ 2027-02-28 (16주)
- 범위: 프론트엔드 (백엔드 일정 제외)
- 개정: 2026-11-10, 명세서 V0.3 → V0.4 (탭 4개 확정, 앱 진입·프로필 커스텀·빈 상태·팝업 추가)
- 개정: 2026-11-12, 1주차 결과 반영 (2주차 단계 나눔, 앞당긴 작업 표시, 디자인 변경·확인 사항 추가)

## 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프레임워크 | Expo (React Native) + TypeScript | iOS·Android 앱 하나로, 폰에서 Expo Go로 바로 확인 |
| 라우팅 | Expo Router (JS Tabs) | 파일 기반, 하단 탭 4개 + 탭 밖 Stack 화면 |
| 스타일 | StyleSheet + theme 토큰 파일 | 설정 이슈 없음, 금액 색상 규칙을 토큰으로 고정 |
| 로컬 상태 / Mock | Zustand | Mock 단계에서 거래·챌린지 CRUD를 실제처럼 동작 |
| 서버 상태 | TanStack Query | 1월 API 연동 시 도입 |
| 캘린더 | 직접 구현 + dayjs | 셀 배경·파랑/초록/빨강/회색 금액 등 커스텀이 많음 |
| 바텀시트 | @gorhom/bottom-sheet | 날짜별 거래내역 |
| 아이콘 | react-native-svg | 탭 · 라인 아이콘 (Figma SVG → 컴포넌트) |
| 캐릭터 · 프로필 이미지 | PNG + expo-image | Figma 돼지 캐릭터가 벡터가 아닌 이미지라 PNG로 내보냄 |
| 폰트 | @expo-google-fonts/noto-sans-kr | 디자인 시스템 폰트 (Regular/Medium/Bold) |
| 프로필 사진 | expo-image-picker | 앨범에서 사진 선택 |
| 알림 | expo-notifications (로컬 예약 알림) | 매일 기록 알림은 서버 없이 가능 |
| 로그인 | 백엔드와 확정 후 결정 (카카오 / Apple / 이메일) | 소셜 로그인은 Expo Go가 아닌 개발 빌드 필요 |
| 빌드·배포 | EAS Build → TestFlight / Play 내부 테스트 | 2월 베타·제출 |
