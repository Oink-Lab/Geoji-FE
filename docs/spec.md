# 0. 서비스 개요

## 0-1. 서비스 정의

거지앱은 다음 네 가지 기능을 중심으로 구성한다.

1. 일반 가계부
2. 소비 분석
3. AI 소비 도우미
4. 절약 챌린지

챌린지는 선택 기능이다.

사용자는 챌린지를 하지 않더라도 일반 가계부로 사용할 수 있다.

서비스 기본 흐름은 다음과 같다.

```
소비·입금 기록
      ↓
월간 가계부
      ↓
소비 분석
      ↓
거지 AI
      ↓
[선택]
절약 챌린지
      ↓
소비 행동 변화
```

자동 카드·계좌 거래수집은 V1 범위에서 사용하지 않는다.

사용자가 직접 기록하는 것을 기본으로 한다.

---

## 0-2. 핵심 서비스 구조

```
                  사용자
                     │
         ┌───────────┼───────────┬───────────┐
         ↓           ↓           ↓           ↓
        홈         챌린지        분석         설정
         │
         ├─ 월 캘린더
         ├─ 거래 기록
         ├─ 챌린지 상태
         │
         └─ 거지 AI
                │
                ↓
             AI 채팅방
```

---

## 0-3. 하단 내비게이션

하단 탭은 총 4개로 구성한다.

```
홈     챌린지     분석     설정
```

| 탭 | 역할 |
| --- | --- |
| 홈 | 월 캘린더 및 기록 |
| 챌린지 | 진행 중 챌린지 / 지난 챌린지 / 새 챌린지 시작 |
| 분석 | 월간 소비 및 챌린지 분석 |
| 설정 | 프로필 / 알림 / 계정 / 앱 정보 |

거지 AI는 별도의 하단 탭으로 제공하지 않는다.

AI 캐릭터는 홈 하단에 상주하며 캐릭터를 누르면 AI 채팅방으로 이동한다.

자산 탭은 V2에서 검토한다. (Figma 「V2 보류」 페이지)

## 0-4. 공통 색상 규칙

## 일반 가계부

금액 앞에 `+`, `-` 부호를 표시하지 않는다.

금액 색상으로 유형을 구분한다.

| 유형 | 색상 |
| --- | --- |
| 소비 | 빨간색 |
| 입금 | 초록색 |

예:

```
12,000   (빨강 = 소비)
50,000   (초록 = 입금)
```

---

## 챌린지

챌린지 기간에는 일반 가계부와 다른 표시 규칙을 사용한다.

| 표시 | 의미 | 색상 |
| --- | --- | --- |
| `+4,000` | 해당 날짜에 4,000원을 아낌 | 초록 |
| `-4,000` | 해당 날짜에 4,000원을 초과 소비 | 빨강 |
| `8,000` | 해당 날짜에 사용할 수 있는 금액 | 파랑 |
| `8,000` | 챌린지 시작 전 일반 소비 | 회색 |

부호는 챌린지 하루 결과(아낌 / 초과)에만 사용한다.

### 계산식

```
일일 차액
=
해당 날짜 사용 가능 금액
-
해당 날짜 실제 소비
```

예:

```
오늘 사용 가능 금액
10,000원

실제 소비
7,000원

→ +3,000원
→ 3,000원 아낌
```

반대로:

```
오늘 사용 가능 금액
10,000원

실제 소비
14,000원

→ -4,000원
→ 4,000원 초과
```

---

## 0-5. 챌린지 성공·실패 핵심 정책

하루 권장금액은 목표 소비를 안내하기 위한 금액이며 성공·실패를 직접 결정하지 않는다.

따라서 하루 권장금액을 초과하여도 즉시 실패하지 않는다.

예:

```
오늘 사용 가능
5,000원

오늘 소비
10,000원

→ 오늘 -5,000원
→ 챌린지는 계속 진행
```

초과 소비한 금액은 남은 예산에 반영되고 이후 날짜의 사용 가능 금액이 감소한다.

## 즉시 실패

다음 조건 중 하나를 만족하는 순간 챌린지는 즉시 실패한다.

```
누적 챌린지 소비 > 챌린지 총예산
```

```
사용자가 챌린지를 포기함 (F110)
```

예:

```
7일 챌린지
총예산 50,000원

누적 소비 49,000원
→ 진행

누적 소비 50,000원
→ 진행

누적 소비 50,001원
→ 즉시 실패
```

## 예산을 정확히 사용한 경우

```
누적 소비 = 총예산
```

이면 실패가 아니다.

챌린지 종료 시까지 추가 소비가 없다면 성공이다.

## 최종 성공

챌린지 종료일까지 실패하지 않은 경우:

```
최종 총소비 ≤ 총예산
```

이면 성공한다.

# 1. 홈

## A100. 홈

홈은 거지앱의 기본 화면이다.

화면 구성은 위에서 아래 순서로 다음과 같다.

```
월 선택 (9월 ▾)            프로필

출금 / 입금 합계

챌린지 배너

월 캘린더

🐷 거지 AI 캐릭터 + 말풍선
```

---

## A101. 이번 달 요약

홈 상단에 이번 달 출금(소비)과 입금 합계를 표시한다.

예:

```
출금 1,243,500   입금 2,100,000
```

- 출금은 빨강, 입금은 초록
- 부호는 붙이지 않는다.

---

## A102. 챌린지 배너

홈 상단에 현재 챌린지 상태를 표시한다.

상태는 네 가지다.

### 챌린지 없음

```
챌린지 해볼래?
정한 돈으로 며칠 버티기        [시작 ›]
```

선택 시 챌린지 시작 화면으로 이동한다.

---

### 챌린지 진행 중

```
5만원으로 7일 버티기          DAY 4 / 7 ›
오늘 쓸 수 있는 돈             7,100원 (파랑)
```

배너 선택 시 챌린지 탭 진행현황으로 이동한다.

---

### 챌린지 실패 후

```
챌린지 재도전                DAY 4에 실패했어 ›
초과                         -21,300원 (빨강)
```

선택 시 이전 챌린지 조건이 기본값으로 입력된 챌린지 시작 화면으로 이동한다.

---

### 챌린지 성공 후

성공한 챌린지 결과를 요약해서 보여준다. (Figma C-6)

## A103. 월 캘린더

월 단위 가계부를 표시한다.

날짜별 소비와 입금을 색상으로 구분한다.

```
소비 → 빨간색
입금 → 초록색
```

부호는 표시하지 않는다.

금액은 축약해서 표시한다.

```
8,000 → 8천
12,000 → 1.2만
2,000,000 → 200만
```

오늘 날짜는 연분홍 배경으로 표시한다.

날짜를 선택하면 해당 날짜의 거래내역 바텀시트를 표시한다.

---

## A104. 홈 빈 상태

기록이 하나도 없는 사용자는 다음과 같이 표시한다. (Figma B-1)

- 출금 / 입금: 0
- 캘린더: 날짜만 표시
- 거지 AI 말풍선: "날짜 눌러서 첫 기록 해볼래?"

# 1-1. 날짜별 거래내역 바텀시트

캘린더에서 날짜를 선택하면 화면 하단에서 바텀시트가 올라온다.

바텀시트가 표시되는 동안 홈 하단의 거지 AI 캐릭터는 숨긴다.

## 거래내역이 없는 경우

회색 텍스트로 표시한다. (Figma B-2)

```
지출 내역이 없어요.
```

## 거래내역이 있는 경우

카테고리와 금액을 표시한다.

예:

```
카페             5,500원
식비            12,000원
교통             3,000원
```

항목을 선택하면 거래 상세 화면으로 이동한다.

우측 하단에는 거래 추가 버튼을 표시한다.

```
+
```

선택 시 기록 화면으로 이동한다.

상단에서 지출과 수입을 전환한다. (Figma D-7)

```

- 금액

- 메모

| 구분 | 카테고리 |

## 기록 완료

# 1-4. 거지 AI 홈 캐릭터

거지 AI는 홈 하단에 상주한다.

캐릭터 옆에 상황에 맞는 말풍선을 표시할 수 있다.

예:

```
오늘 아직 기록 안 했는데?

쇼핑을 이번 달 갑자기 많이 하네?

이번 달 분석 나왔어. 한번 볼래?

기록 까먹지 않게 알람 맞춰줄까?
```

캐릭터 자체를 선택하면 AI 채팅방으로 이동한다.

말풍선을 선택하면 말풍선 내용에 맞는 화면(채팅 / 분석 / 알림 설정)으로 이동한다.

# 2. 챌린지

# F100. 챌린지 탭

챌린지 탭은 다음으로 구성한다. (Figma D-17)

```
챌린지                            [+ 새 챌린지]

[진행 중 카드]
진행 중 · 5만원으로 7일
DAY 4 / 7
오늘 쓸 수 있는 돈 7,100원
[챌린지 포기하기]

지난 챌린지
9월 2주차   7일 · 45,000원   실패   -3,200
9월 1주차   7일 · 50,000원   성공   +3,500
...
```

## 챌린지 이력이 없는 경우

빈 상태를 표시한다. (Figma B-3)

```
아직 챌린지가 없어
7일 동안 5만원으로 버티기 같은 목표를 정해보자.
하루 쓸 돈은 내가 계산해줄게.

[첫 챌린지 시작하기]
```

이력이 없을 때 빈 상태를 보여줄지, 바로 챌린지 시작 화면으로 이동할지는 확정이 필요하다. (12. TBD)

# 2-1. 챌린지 시작

챌린지 생성 시 다음 정보를 입력한다.

### 입력항목

- 며칠 버틸지
- 얼마로 버틸지
- 하루 사용 가능 금액 (자동 계산, 표시만)
- 기록 알림 시간
- 챌린지 이름

---

## 챌린지 기간

사용자가 챌린지를 진행할 일수를 설정한다.

```
3일   7일   14일   직접 입력
```

---

## 총예산

해당 챌린지 기간 동안 사용할 총금액을 입력한다.

예:

```
50,000원
```

---

## 최초 하루 사용 가능 금액

시작 시 자동 계산한다.

```
총예산 ÷ 챌린지 일수
```

예:

```
7일
70,000원

→ 하루 10,000원
```

사용자가 직접 입력하는 값이 아니라 자동 계산된 결과를 표시한다.

# F101. 동적 하루 사용 가능 금액

챌린지 진행 중 매일 동일한 금액을 강제하지 않는다.

소비결과에 따라 다음 날부터 사용할 수 있는 금액을 다시 계산한다.

```
남은 챌린지 예산
──────────────
남은 챌린지 일수
```

예:

```
총예산
70,000원

DAY 1 권장
10,000원

DAY 1 실제 소비
5,000원
```

남은 예산:

```
65,000원
```

남은 기간:

```
6일
```

다음 날 사용 가능 금액:

```
65,000 ÷ 6
≈ 10,833원
```

따라서 하루에 아끼면 이후 사용할 수 있는 금액이 늘어나고, 하루에 많이 쓰면 이후 사용할 수 있는 금액이 줄어든다.

# F102. 챌린지 알림

챌린지 진행 시 기록 알림시간 설정을 필수로 한다.

이미 알림시간이 설정된 사용자라면 기존 알림 설정값을 보여주고 수정할 수 있다.

챌린지를 하지 않는 사용자는 설정 탭에서 자율적으로 기록 알림을 설정할 수 있다.

# 2-2. 챌린지 진행 중 홈

챌린지가 진행 중일 때 홈 캘린더의 일부 UI가 변경된다.

## 챌린지 기간 표시

챌린지에 해당하는 날짜 영역을 연한 파란색 반투명 배경으로 표시한다.

## 사용 가능 금액

앞으로 남은 챌린지 날짜에는 파란 글자로 해당 날짜에 사용할 수 있는 금액을 표시한다.

## 지나간 챌린지 날짜

하루 결과를 `+아낌`(초록) / `-초과`(빨강)으로 표시한다.

## 챌린지 시작 전 거래

챌린지 시작 전에 기록된 일반 가계부 소비는 회색으로 표시한다. 부호는 붙이지 않는다.

이를 통해 현재 챌린지 소비와 기존 거래를 구분한다.

캘린더 아래에 범례를 표시한다.

```
파란 글자 = 그 날 쓸 수 있는 돈 · 회색 = 챌린지 전 일반 기록
```

# 2-3. 챌린지 기록 화면

챌린지 진행 중 기록 화면은 일반 기록 화면과 일부 UI가 다르다.

상단에 진행 일차와 오늘 사용할 수 있는 금액을 파란색으로 표시한다.

```
DAY 4 / 7
오늘 쓸 수 있는 돈
7,100원
```

사용자가 금액을 입력하면 남은 사용 가능 금액을 실시간으로 계산한다. (Figma D-8)

```
입력 4,700원

이대로 기록하면
+2,400원 남음
```

예:

```

5,000원

입력
10,000원

5,000원 초과
```

이 상태 자체는 챌린지 실패가 아니다.

## 총예산 소진 경고

입력금액을 저장하면 누적 소비가 총예산을 넘는 경우, 저장 전에 경고를 표시한다. (Figma D-9)

# 2-4. 챌린지 실패

챌린지가 실패하면 실패 결과 화면으로 이동한다.

화면에는 다음 내용을 표시한다.

- 실패 안내
- 사용한 총금액
- 설정한 총예산
- 실패한 시점
- AI 실패 원인 분석

AI는 실제 챌린지 기간의 소비기록을 기반으로 실패 원인을 설명한다.

예:

```
이번에는 카페보다 배달에서 돈이 많이 나갔어.
특히 마지막 이틀 소비가 컸어.
```

하단 버튼:

```
[같은 조건으로 다시]

[새로 정하기]
```

우측 상단 홈 아이콘 선택 시 일반 가계부 홈으로 이동한다.

---

# F108. 실패 후 홈 표시

실패한 챌린지를 종료하고 홈으로 돌아가더라도 해당 챌린지 기록은 유지한다.

챌린지를 진행했던 날짜를 빨간색 반투명 배경으로 표시한다.

상단 배너는 "챌린지 재도전" 상태로 표시한다. (A102)

---

# 2-5. 챌린지 성공

챌린지 종료일까지 누적 소비가 총예산을 넘지 않으면 성공한다.

성공 화면에서 다음 정보를 제공한다.

- 챌린지 이름
- 기간
- 총예산
- 실제 소비
- 남은 금액
- 하루 평균 소비
- 가장 많이 소비한 카테고리
- 가장 많이 소비한 날짜
- 권장금액 이하였던 날짜 수
- 권장금액을 초과했던 날짜 수

AI가 결과를 간단하게 분석한다.

예:

```
이번에는 초반에 돈을 아껴둔 게 컸어.
마지막 이틀에 조금 더 써도 예산을 지킬 수 있었어.
```

예산을 거의 다 쓰고 성공한 경우 "아슬아슬 성공" 화면을 표시한다. (Figma D-16)

---

# F109. 성공 후 홈 표시

성공한 챌린지 기간은 홈 캘린더에서 초록색 반투명 배경으로 표시한다. (Figma C-6)

# 2-6. 지난 챌린지 목록

챌린지 탭 하단에 과거 챌린지를 목록으로 표시한다. (F100)

각 항목에는 다음 정보를 표시한다.

- 챌린지 기간 이름 (예: 9월 2주차)
- 기간 · 총예산
- 성공 / 실패
- 최종 결과 금액 (+아낌 / -초과)

목록에서 챌린지를 선택하면 당시 결과 화면을 다시 확인할 수 있다.

이번 달 왜 이렇게 많이 썼어?

이번 달 카페에 얼마 썼어?

이번 달 내가 제일 많이 쓴 게 뭐야?

지난 챌린지는 왜 실패했어?
```

AI는 사용자의 실제 기록 데이터를 활용하여 답변한다.

기록이 부족해 답하기 어려우면 그 사실을 안내한다. (Figma D-14)

# G102. 소비 판단 질문

사용자는 구매 전 AI에게 의견을 물을 수 있다.

예:

```
이거 살까 말까?
```

가능한 경우 AI는 다음 정보를 참고한다.

- 이번 달 소비
- 해당 카테고리 소비
- 최근 소비 패턴
- 현재 챌린지 여부
- 남은 챌린지 예산

답변에 근거가 된 수치를 카드 형태로 함께 보여줄 수 있다.

```
옷 · 최근 3개월        40,000
남은 챌린지 예산        31,200
```

단순히 구매를 금지하는 방식이 아니라 소비상황을 설명하고 사용자가 판단할 수 있도록 한다.

# F203. 실패 판정

# 7. 홈 챌린지 캘린더 상태

챌린지와 일반 가계부 기록이 하나의 달력에 표시된다.

| 상태 | 배경 | 금액 표시 |
| --- | --- | --- |
| 일반 날짜 | 흰색 | 소비 빨강 / 입금 초록, 부호 없음 |
| 오늘 | 연분홍 | 일반 날짜와 동일 |
| 챌린지 시작 전 기록 | 흰색 | 회색, 부호 없음 |
| 진행 중 챌린지 · 남은 날 | 연파랑 반투명 | 사용 가능 금액 파랑 |
| 진행 중 챌린지 · 지나간 날 | 연파랑 반투명 | +아낌 초록 / -초과 빨강 |
| 성공한 챌린지 기간 | 초록 반투명 | 하루 결과 |
| 실패한 챌린지 기간 | 빨강 반투명 | 하루 결과 |

# 14. V0.4 핵심 정책 요약

```
1. 하단 탭
   → 홈 / 챌린지 / 분석 / 설정 (4개)
   → 자산 탭은 V2

2. 앱 진입
   → 스플래시 → 로그인 → 닉네임 설정
   → 온보딩은 V2

3. AI
   → 별도 탭 없음
   → 홈 하단 캐릭터에서 진입

4. 일반 가계부
   → 소비 빨강
   → 입금 초록
   → +/- 부호 사용하지 않음

5. 기록
   → 지출 / 수입 전환
   → V1은 고정 카테고리

6. 챌린지
   → 선택 기능

7. 하루 사용 가능 금액
   → 남은 예산 ÷ 남은 일수로 매일 변경

8. 챌린지 +
   → 아낀 돈
   → 초록색

9. 챌린지 -
   → 초과해서 쓴 돈
   → 빨간색

10. 하루 권장금액 초과
    → 실패 아님

11. 누적 소비가 총예산 초과
    → 즉시 실패
    → 저장 전 경고 표시

12. 누적 소비 = 총예산
    → 실패 아님

13. 챌린지 포기
    → 실패로 기록

14. 챌린지 종료 시
    → 총소비 ≤ 총예산이면 성공

15. 실패 챌린지 기간
    → 홈 캘린더 빨간 반투명

16. 성공 챌린지 기간
    → 홈 캘린더 초록 반투명

17. 진행 중 챌린지 기간
    → 연파랑 반투명

18. 챌린지 이전 일반 소비
    → 회색 표시, 부호 없음

19. 챌린지 알림
    → 챌린지 진행 시 필수

20. 설정
    → 프로필 수정(사진·캐릭터·닉네임·소개) / 기록 알림 / 계정 삭제 / 앱 정보

21. 분석
    → 월 단위
    → 카테고리별 소비
    → 챌린지 통계

22. 자동 거래수집
    → V1 제외
```
